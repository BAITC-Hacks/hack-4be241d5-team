# Есть дефект или нет

Небольшой классификатор изображений: скрипт получает путь к файлу и печатает
`OK` либо `DEFECT`. Модель машинного обучения не используется — решение
принимается по доле красных пикселей.

## Как запустить

Нужен Python 3.10 или новее.

```bash
python -m venv .venv
```

Активируйте окружение:

```bash
# Windows
.venv\Scripts\activate

# Linux/macOS
source .venv/bin/activate
```

Установите зависимость и запустите классификатор:

```bash
pip install -r requirements.txt
python classify.py ok.png
python classify.py defect.png
```

Ожидаемый вывод:

```text
OK
DEFECT
```

## Что получилось

Каждый пиксель считается красным, если красный канал ярче 150 и как минимум
на 25% сильнее зелёного и синего. Если таких пикселей больше 30% от площади
изображения, скрипт выводит `DEFECT`; иначе — `OK`.

В репозитории лежат два тестовых цветных изображения: сине-зелёный `ok.png`
и преимущественно красный `defect.png`.
